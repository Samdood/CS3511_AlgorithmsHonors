# CS 3511: Algorithms Honors

A collection of homework assignments and a midterm from CS 3511 (Design and Analysis of Algorithms honors) at Georgia Tech, where I served as a teaching assistant.

## Course materials

- [Homework 1](hw1.pdf): Proof techniques, asymptotic analysis, bit complexity, loop invariants, modular exponentiation
- [Homework 2](hw2.pdf): Loop invariants and correctness proofs, merge sort, Fermat’s little theorem, modular inverses, quadratic residues
- [Homework 3](hw3.pdf): Modular arithmetic, linearity of expectation, recurrences, divide-and-conquer range-sum counting, randomized load balancing
- [Homework 4](hw4.pdf): Lagrange interpolation, roots of unity and the FFT, polynomial multiplication, generating functions for coin-flip probabilities
- [Homework 5](hw5.pdf): Minimum spanning trees and bottleneck paths, Dijkstra’s algorithm, bridges, resource-constrained shortest paths
- [Homework 6](hw6.pdf): Strongly connected components, minimum spanning forests, dynamic programming, optimal solution reconstruction, greedy counterexamples
- [Midterm](midterm.pdf)
